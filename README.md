# Tip & Bill Splitter
This project help you to split bill between your friends after calculating the bill and tip together.

## Overview
The frustrastion to split bill among friends will be enhancely reduced with the help of Tip & Bill Splitter. Tip & Bill Splitter is created for those easy-going people with many friends to eat with. This project will calculate and split the total bill for you, so you don't need to do it yourself.

## Features
- Calculate tip from bill
- Calculate total bill and tip together
- Split the bill to the number of people
- Showing the bill summary

## Technologies Used
- Language: Python

## Prerequisites
Python 3.13

## Usage
Use this file to run it in your computer terminal.
